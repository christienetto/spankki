New payment

SEPA credit transfer via the Payment Initiation API. You'll approve it on S-Pankki's sandbox login page.

Requires your application to be subscribed to Payment Initiation API (v3.1.7) in the Crosskey portal.

What happens

  1. App token — client-credentials grant with scope payments.
  2. Payment consent — POST /international-payment-consents, body signed with your digital signature key (x-jws-signature).
  3. Approval — you log in at S-Pankki; intent urn:s-pankki:payment:{ConsentId}.
  4. User token — authorization code exchanged (payment tokens can't be refreshed).
  5. Funds check — GET …/funds-confirmation.
  6. Submit — signed POST /international-payments. Check its status here, then see it in Overview → Transactions.
